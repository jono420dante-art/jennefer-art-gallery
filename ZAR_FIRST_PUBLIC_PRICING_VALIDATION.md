# ZAR-First Public Pricing Validation

## Public Browser Review — 21 August 2026

The public home gallery confirms that saved prices render in the requested order: **ZAR is the primary first line** and **USD is directly beneath it**. For example, the Riana featured card renders `R 11000.00` followed by `$800.00 USD`.

The public gallery loaded without browser-console errors while the same-origin Administrator-to-public artwork refresh listener was active. Administrator saves invalidate local artwork detail, collection, featured, and list queries and broadcast a same-origin refresh signal so open gallery tabs request current database data.

No live artwork or price was altered for this review.
